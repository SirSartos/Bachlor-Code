Wie man den Code benutzt.

1. Erstellen eines Unity 3D projekts
2. Importieren des Asset folders über drag and drop in die Hirarchie.
3. Im ordner Script gibt es die Scripts GrowHelper und die 3 Algorithmen.
4. GrowHelper auf eine Gameobjeckt hinzufügen.
5. 1 der 3 Algorithmen auf einem Gameobjekt hinzufügen.
6. die Objects für die dependencies der Scipts finden sie im ordner Prefabs. (Stamm und SpacePoints)
7. die Parameter können sie aus der Arbeit entnehemen.
8. nach dem Starten können die Bäume mit d erstellt und mit T die AstPunkte (SpacePoints) ausgeblednet werden.
